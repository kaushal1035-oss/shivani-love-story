SHIVANI LOVE WEBSITE

1. Extract this ZIP file.
2. Open the extracted folder "ShivaniLoveWebsite".
3. Double-click index.html to open it in Chrome.
4. The images folder must stay beside index.html. Do not move the photos out of it.
5. To change the letter, open index.html in VS Code and edit the text inside the section with id="love-letter".
6. To change "Your favourite person" to your name, search for that phrase in index.html and replace it.

This folder runs locally in your browser. To publish it online, upload index.html and the entire images folder to your chosen static website host. Anyone who can access the public link may see the photos.
